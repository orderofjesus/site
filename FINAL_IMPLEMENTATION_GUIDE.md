## 🚀 **DEPLOYMENT STEPS**

### **Step 1: Environment Setup**
```bash
# 1. Install additional dependencies
npm install stripe @stripe/stripe-js

# 2. Add environment variables to .env.local
STRIPE_SECRET_KEY=sk_test_...
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_test_...
STRIPE_WEBHOOK_SECRET=whsec_...

# Stripe Price IDs (generated by setup script)
NEXT_PUBLIC_STRIPE_ALL_ACCESS_MONTHLY_PRICE_ID=price_...
NEXT_PUBLIC_STRIPE_ALL_ACCESS_YEARLY_PRICE_ID=price_...
NEXT_PUBLIC_STRIPE_MYSTICAL_MONTHLY_PRICE_ID=price_...
NEXT_PUBLIC_STRIPE_MYSTICAL_YEARLY_PRICE_ID=price_...
NEXT_PUBLIC_STRIPE_OPEN_SCROLL_MONTHLY_PRICE_ID=price_...
NEXT_PUBLIC_STRIPE_OPEN_SCROLL_YEARLY_PRICE_ID=price_...
```

### **Step 2: Database Schema Deployment**
```bash
# Deploy the updated schema to Convex
npx convex dev  # This will deploy the new schema automatically
```

### **Step 3: Stripe Configuration**
```bash
# Run the automated Stripe setup script
npx tsx scripts/setup-stripe-products.ts

# This will:
# - Create all subscription products in Stripe
# - Set up webhook endpoints
# - Generate environment variables for you to copy
```

### **Step 4: Content Seeding**
```bash
# Populate your content library with sample content
npx tsx scripts/seed-content-library.ts

# This creates sample content for both schools:
# - Mystical Masterclass videos and courses
# - Open Scroll prophetic content
# - General spiritual content
# - Bundle offerings
```
